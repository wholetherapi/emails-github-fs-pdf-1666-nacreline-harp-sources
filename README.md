# Nacreline Fog Harp — Design Package

Released design package for the **Nacreline Fog Harp, Revision 2** (internal design ID
`NFH-2`).

## Contents
- `hardware/` — harp frame, mesh tensioners and droplet-sensor board (KiCad 8)
- `firmware/` — low-power droplet counter and mesh-vibration cancellation firmware
- `docs/` — bill of materials and build guide
- `enclosure/` — transport crate drawings

## Release status
The NFH-2 package shipped with the spring 2026 production run. All fabrication files are
final and correspond to the Rev 2 frame and tensioner hardware.
